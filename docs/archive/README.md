# Archive

These files preserve completed plans and earlier research. They describe the
project at the time they were written and may conflict with the current app.
Use the [current documentation index](../README.md) for implementation guidance.

- `phase-1/`: completed P1-M1 through P1-M12 plans and hardware evidence.
- `research/`: initial protocol, security, and Wake research incorporated into
  later decisions.
- Root files: superseded architecture, information architecture, and design
  review documents.
