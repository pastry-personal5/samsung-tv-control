# Version v1.0.0

Samsung TV Remote v1.0.0 delivers secure local discovery, certificate checking,
TV-approved pairing, saved-TV reconnect, remote controls, and Wake on LAN.

The macOS interface includes the visual remote, explicit power and Wake
controls, a saved-TV management table, and a concise Global Messages Pane.
Play/Pause uses inferred command state; it does not claim observed TV playback
state. Sources, Apps, and Text Input remain placeholders.
